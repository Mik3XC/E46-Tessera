# Security

This project is experimental and has no supported production release.

Report suspected wallet, signing or consensus vulnerabilities privately to
**3xcypher@proton.me**, addressed to **Mik3XC**. Describe the affected source,
expected behavior, observed behavior, and reproduction steps using dummy data.
Do not send passwords, private seeds, wallet files, or unrelated personal data.

No response-time guarantee or bounty program is established by this document.
The project will coordinate disclosure after reviewing the report.
